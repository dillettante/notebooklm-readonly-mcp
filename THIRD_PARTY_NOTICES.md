# Third-party dependencies

This adapter uses, rather than vendors, the following projects:

- [notebooklm-py](https://github.com/teng-lin/notebooklm-py), MIT; the underlying unofficial NotebookLM client.
- [MCP Python SDK](https://github.com/modelcontextprotocol/python-sdk), MIT; transports and OAuth resource metadata.
- [PyJWT](https://github.com/jpadilla/pyjwt), MIT; JWT verification.
- [cryptography](https://github.com/pyca/cryptography), Apache-2.0 OR BSD-3-Clause; cryptographic primitives.

Their distributions include their own licenses and copyright notices. See the exact pinned dependency
versions in `uv.lock` and their installed metadata. This repository's license applies to its own adapter
code and documentation. No Google, OpenAI or Anthropic endorsement is implied.
